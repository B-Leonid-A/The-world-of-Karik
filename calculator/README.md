# Калькулятор

Простое веб-приложение калькулятора на чистом HTML, CSS и JavaScript (без фреймворков и зависимостей).

## Возможности

- Четыре арифметические операции: `+`, `−`, `×`, `÷`, а также остаток от деления `%`
- Приоритет операций (сначала `× ÷ %`, затем `+ −`) — вычисляется собственным парсером, без `eval`
- Десятичные дроби, унарный минус, смена знака `±`
- Предпросмотр результата во время ввода
- Безопасное поведение: деление на ноль показывает «Ошибка»
- Поддержка клавиатуры: цифры, `+ - * / %`, `.` или `,`, `Enter`/`=` — вычислить, `Backspace` — стереть, `Esc` — сброс
- Разделитель-запятая для дробей (как принято в русской локали)

## Структура

```
calculator/
├── index.html   # разметка
├── style.css    # тёмная тема, сетка кнопок
└── app.js       # логика: токенизация + рекурсивный спуск
```

## Запуск

Просто откройте `calculator/index.html` в браузере:

```bash
# macOS
open calculator/index.html
# Linux
xdg-open calculator/index.html
# Windows
start calculator\index.html
```

Либо запустите локальный сервер:

```bash
python3 -m http.server 8000 --directory calculator
# затем откройте http://localhost:8000
```
