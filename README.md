# The-world-of-Karik

## 🧮 Веб-приложение «Калькулятор»

Приложение находится в папке [`calculator/`](./calculator/) (HTML + CSS + JS, без зависимостей).
Подробности — в [README калькулятора](./calculator/README.md).

### 🚀 Кликабельная ссылка для запуска

Локальный сервер запущен — просто перейдите по ссылке:

| Сервер | Ссылка |
|--------|--------|
| Порт 3000 | 👉 **[http://localhost:3000](http://localhost:3000)** |
| Порт 8000 | 👉 **[http://localhost:8000](http://localhost:8000)** |
| Порт 8001 | 👉 **[http://localhost:8001](http://localhost:8001)** |

Без сервера — откройте файл напрямую:
👉 **[calculator/index.html](./calculator/index.html)**

### Перезапуск сервера одной командой

```bash
./launch.sh          # порт 8000 по умолчанию
./launch.sh 5000     # любой другой порт
```

После запуска скрипт выведет кликабельную ссылку `http://localhost:<порт>`.
